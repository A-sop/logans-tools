## A9 (AC1 grants, A6 / guard 4i) PUBLIC TEMPORARY on the database is allowed

Prod (Neon `neondb`, PG 18.x) materialises PUBLIC database ACL as `=Tc/neondb_owner` —
CONNECT and TEMPORARY for PUBLIC, granted by the owner. That is normal and required for
session temp tables. Guard 4i must **refuse PUBLIC CREATE** on the database when it appears
as an ACL entry, and must **not** refuse PUBLIC TEMPORARY (or CONNECT).

Tests:
- Apply succeeds against a database whose `datacl` matches prod (`=Tc/<owner>`, no pre-revoke
  of TEMPORARY from PUBLIC).
- PUBLIC CREATE on the database still aborts guard 4i.
